# YOGHAN — Advanced Fibres & Polymers

Surat's premier manufacturer of high-tenacity Nylon Yarn (FDY, POY, DTY, HOY), Polyamide 6 Chips, and industrial-grade Ammonium Sulphate.

## Live Website
The site is deployed and viewable on GitHub Pages:
👉 **[https://bhavarth007.github.io/Yoghan/](https://bhavarth007.github.io/Yoghan/)**

## Features
- **Commercial Responsive Design**: Optimized across mobile, tablet, and widescreen desktop layouts.
- **Interactive Product Catalogue**: Dual-layer filtering by Category (Regular, Specialty, Chips, Fertilizer) and Series (FDY, HOY, POY, DTY) with real-time search.
- **Animated Mega-Menu & Mobile Drawer**: Smooth slide-down mega-menu on desktop, animated hamburger with accordion on mobile.
- **Yarn Yield & Conversion Calculator**: Instant conversion for Linear Length (m), Decitex (dtex), English Cotton Count (Ne), and Metric Count (Nm).
- **Quality Assurance & Specs Bench**: Laboratory testing parameters for FDY, DTY, PA6 polymer chips, and Ammonium Sulphate.
- **Commercial Quote Request Drawer**: Pre-filled quotation inquiry modal with reference generation.
- **Fiber Weaving Canvas**: Real-time interactive physics-based thread weaving animation in hero section.

## Tech Stack
- HTML5 / CSS3 (Custom Variables, Flexbox, CSS Grid, Smooth Cubic-bezier Animations)
- Vanilla JavaScript (Zero external runtime dependencies)
- Typography: Fraunces & Inter (Google Fonts)
